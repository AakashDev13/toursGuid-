# Tours API

A RESTful API backend for managing tour and travel information. This project is part of the Tours Guide application and is designed to provide backend functionality for tour-related data.

## Features

- RESTful API architecture
- Tour data management
- Organized backend structure
- Development workflow using NodemonTech Stack
- **Node.js**
- **Express.js** (if configured in the project)
- **Database:** As configured in the project
- **Nodemon** : for automatic server restarts during development
- **Postman** : for Tesing APIs

## Getting Started

### Prerequisites

- node
- npm

### 1. Clone the repository

```bash
git clone https://github.com/AakashDev13/toursGuid-.git
cd toursGuid-/tourAPIs
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
 nodemon app.js
```

If your entry-point file is named `app.js` or `index.js`, replace `server.js` with the correct filename.

Alternatively, if Nodemon is configured in `package.json`, run:

```bash
npm run dev
```
